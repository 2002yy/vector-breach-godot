# 地图坐标与移动表面的原光探针诊断

基线 main `2e0187874c500004ac517bab7cfd9d625f5024eb`，分支 `feat/map-probe-runtime-20261021`。本片不等待 CI，亦不依赖 #57/#58 的未合并代码。输入是 [#58](https://github.com/2002yy/vector-breach-godot/pull/58) 已验证的本机原图集/JSON 数据合同；本片的原生测试使用自建微型浮点体积，不要求 CI 拥有 Valve 私有资产。

## 已实现

- `SourceProbeDiagnostic.gd` 明确要求诊断同意参数、匹配的关卡 ID/原 VPK SHA256、有限等比变换、受支持探针及经 SHA256 验证的 RGBA32F 图集。拒绝跨地图、错误布局/尺寸、路径逃逸、超过当前 128 探针/图集容量、未实例化子实体等输入。
- 从实际 `VisualRoot/LevelVisual` 下唯一的 `OfficialSourceAlignment` 节点读取世界变换，再组合 VRF 原坐标轴/0.0254 米单位。不能对整个关卡含糊查找：碰撞层也保留同名对齐节点。两图转换结果另与既有独立 metadata 的轴向/缩放/平移逐出生点核对，正向误差小于 0.1mm，反向小于 0.01 源单位。
- `source_probe_sampling.gdshaderinc` 逐片元支持坐标逆变换、绕 Z 的体积旋转、图集半 texel 边界、六面方向平方权重、边界淡出、稳定的优先级顺序和最多四体积混合。缺少覆盖时返回实际覆盖率；诊断画面用品红标记缺口，不补造 SH1 环境光。
- 只在自有材质副本附加诊断 pass，保留原 Shader/纹理/骨骼渲染路径；重复附加不会叠加，已有外来 pass 会保留，卸载恢复原表面覆盖。重新配置或失败时还会清除已绑定的旧纹理/探针数量，避免沿用上一张图。
- `MapProbeRuntimeProbe.tscn` 加载现有完整关卡视觉和独立碰撞层，使用原出生点及真实地面射线定位角色；不会改动关卡文件、碰撞、移动、命中、AI 或比赛规则。显示的是**纯探针辐照度诊断色**，不属于最终材质/距离对比度效果。
