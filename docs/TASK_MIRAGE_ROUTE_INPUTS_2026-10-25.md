# Movement-4 R2：Mirage 通路、首落点与 Modern 起步停滞

基线 `f73eda69b612308394d90989ca56a6a671765f9b`（#96 R1），分支 `audit/mirage-route-input-diagnostics`。保留原地图/资产、Current 默认及参数、Legacy 模型、原 90 次和 R1 凭据。修复的是 **Modern 可选候选的地面加速参考**，不是改最大速度、跳跃数值、摩擦或目标容差；不发布试玩包、不推进 Movement-5。

## 三个不同结论

1. **Mirage 原助跑目标存在受控的可达通路。** 原冻结导航图给出 44 节点阶梯绕行，Current 的不跳/静步反馈发现后，录制实际方向输入，另冻 schema-3 清单；关闭反馈后在 60/120 Hz 开环回放，均无需跳跃、有原碰撞支撑地进入原目标区，约 **4.97/4.98 秒**（不跳前进）和 **4.88/4.94 秒**（静步）。没有瞬移、改碰撞或改终点。
2. **原直跳的首落点精度与后来到达是两件事。** Current 原输入首次落地在圈外，但继续移动约 **1.02/1.01 秒**即进入目标，Legacy/Modern 原助跑输入也有后续受支撑到达。不能把 R1 的 outside_target 一概称为“通道不存在”。原首落点成绩不改，原直跳资格不因后续到达而悄悄放行。绕行输入未做最短路/真人优化，不能用这些秒数断言实战节省时间。
3. **Modern 蹲行停滞是确定的候选实现缺陷。** 蹲行后 wish_speed 被同时用于限速与加速强度，导致加速低于停止摩擦，速度困在单 tick 增量；60/120 Hz 的约 2 倍差来自这套组合，不应拿来评价原版 CS2。

## 停滞复现与修复

Modern 步枪未开镜速度 5.461 m/s，蹲行倍率 0.34，最终上限 **1.85674 m/s**。旧地面加速 `5.5 × 1.85674 ≈ 10.2121 m/s²`，小速度时停止摩擦 `5.2 × 2.032 = 10.5664 m/s²`，每帧先清零速度，再加一个小增量。原起跳前稳定在 **0.170201 / 0.085101 m/s**（60/120 Hz）；延长地面助跑也无法消除。

现将 Modern 加速参考与最终姿态上限分开：使用当前枪型和开镜状态的武器速度作加速参考，蹲行/静步/受击/水体继续限制最终速度。原参数 5.5、5.2、80 u/s 与各武器/姿态上限不改；受击状态没有被清除。Scoped AWP 仍用其开镜速度参考，不偷用未开镜速度；Current/Legacy 继续走原有规则。

修复后，两档在原 0.1 秒起跳前都能达到 **1.85674 m/s**。实际平地玩家覆盖步枪、开镜狙击枪、手枪、霰弹枪的蹲行/静步及受击后起步；纯规则检查另覆盖受击/水体/姿态限速组合。

## 输入和姿态对照

在同起点、目标、半径 1.6 m、原碰撞及两档频率下，预先冻结 6 个对照：原助跑输入、原预蹲输入、延长预蹲助跑至 0.5 秒起跳、站立起跳后空中蹲伏、两条录制的阶梯绕行输入。修复前后各三方案/两档，共 **72 次**，另有 2 次反馈发现。清单、父哈希、发现数据哈希、前后实际 Player/Rules 源文件哈希均保存本机，不用 git HEAD 标签替代未提交源码身份。

前后实测中，**Current 和 Legacy 的这些完整物理轨迹逐值一致**，不只是最终速度相同。Modern 原预蹲的首落点误差由约 **2.46/2.48 m** 改为约 **1.70/1.77 m**，仍大于 1.6 m，原首落点依旧失败；但约 **0.78/0.79 秒**后已在原碰撞支撑下进入目标。Legacy 原预蹲首次落地也在圈外，约 **1.08/1.13 秒**后能沿平台走入目标。

因此，R1 四次未达标不能全部叫“跳不上平台”；它们包含首落点指定区域的精度要求。后续到达有独立脚印射线支撑证据，单独记录，**不覆盖原首落点 verdict，也不改 20/24 或原 52/90**。三图原合格子集再次回放 24 次仍为 **20/24**；未改图、改半径来让数字变绿。

反馈路线只用于发现，正式证据使用已录制时间线的开环回放；Current 时间线对其他方案的失败不能证明其他方案不可达，因为速度和转向响应不同。此处是物理边界的方向输入夹具，**不是原生键鼠操作、真人手感或最优路径验收**。输入研究 schema 3 明确 `formal_qualification=false`，不能取代 R1 的逐点资格门闸或让 Movement-5 放行。
