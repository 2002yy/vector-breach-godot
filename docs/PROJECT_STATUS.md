## 当前主线

- Godot 4.6 是当前可玩主线；旧 Babylon/WebGL 实现仅作历史参考。
- 当前目标不是逐帧复制旧引擎，而是保留经典 CS 的跳跃、蹲跳、枪械纪律和爆破决策，并采用现代战术射击游戏更清晰的地面启停与受击减速。
- 所有地图共享同一套玩家移动、跳跃、雷达范围和战斗规则。

## 敌人/队友实体当前边界

### 已具备

- 地图 JSON 可定义单位名称、T/CT 阵营、出生位置、朝向、护甲、头盔和武器字段；`friendly` / `enemy` 会根据本地玩家阵营自动解析。
- 使用 `CharacterBody3D` 胶囊参与地图、玩家和队友碰撞；当前友方单位会真实阻挡玩家。
- 共用现有伤害模型，支持头、胸、腹、手臂、腿五类命中部位，以及护甲、头盔、爆头和穿透后的伤害结算。
- 支持受伤、死亡、关闭碰撞、移除实体、队伍存活人数变化、敌方击杀奖励和淘汰胜负判断；友军伤亡不会发放击杀金钱。
- 友方单位始终进入雷达；敌方单位只有在距离、视角、无遮挡和无烟雾阻断等合法侦测条件满足后才短暂显示。
- 当前使用蓝色 CT、橙色 T 的胶囊和简单武器灰盒，仅用于验证碰撞、伤害、队伍和雷达协议。
- `combatTargets` 默认运行 AI；可通过 `aiEnabled: false` 保留静态训练靶。`teamActors` 可由 JSON 显式启用 AI；Gatehouse/Core Vault 已启用 3 名 T 进攻 AI。
- Bot 会把 `aiRoutes` 与现有 `routes` 合并为共享连接图；重合节点自动合并，路线相邻点建立双向边，追查声音与巡逻时使用带危险/掩体/通行代价的 A* 并定期重算。边可标记精确、蹲伏和梯子通行；连续 0.75 秒无有效位移会进入脱困。Foundry 当前实测生成 46 个导航节点。
- Bot 可合法发现本地玩家和异队 Bot，烟雾会阻断视线；玩家普通/静步脚步、落地和枪声会按不同半径写入听觉记忆。
- Bot 发现目标后经历反应/瞄准阶段，急停至射击速度门限，再按短点射和间隔开火；弹匣耗尽后会换弹。命中共用玩家命中部位、护甲、受击减速与死亡链。
- AI 枪声和脚步已接入现有空间音频，AI 击杀可写入击杀信息。
- T/CT Bot 会按地图目标区执行携带/安装/回防/拆除；安装与拆除使用持续交互，并受 `interaction_owner` 归属保护，玩家输入不会打断 AI 交互。

### 尚未具备

- 当前仍是带属性连接图，不是完整导航网格；已有静态危险/掩体代价和脱困，但没有导航面、跳跃连接、按伤亡动态积累危险、离路线自由寻路和复杂高低差择路，未标注区域仍可能无法到达。
- 感知已处理受伤来源、投掷物声响、队友报点共享和 C4 状态；尚未处理完整队伍战术分工（补枪、回防优先级）与语音报点。
- 会在交火中主动蹲伏、侧移躲闪、架枪、低血量撤退、距离切枪和分级火力；但还没有完整 30 发后坐力轨迹补偿、动态准星压枪和 AI 武器/装备库存管理。
- AI 已具备完整基础武器库存、跨回合保枪、团队经济分级、补枪报告、距离化投掷与曲线压枪；尚未有玩家侧压枪训练、投掷物落点统计校准与完整队伍战术树。
- 已有同队报点、T 分路（主攻/支援/牵制）与 CT 分点回防，但仍无补枪优先级、保枪、经济局与完整队伍战术树。
- 没有正式角色模型、骨骼，以及持枪、移动、开火、换弹、受击和死亡动画；敌人已有空间脚步/枪声事件，但仍使用合成音，且没有语音表现。
- 玩家死亡后仍按单机训练逻辑结束本地回合，不能观察或接管仍存活的 AI 队友。
- 没有多人服务器权威、状态复制、延迟补偿、命中校验和断线重连。
- 计分板尚未维护每个战术单位的击杀、助攻、死亡、金钱、装备和网络状态。
