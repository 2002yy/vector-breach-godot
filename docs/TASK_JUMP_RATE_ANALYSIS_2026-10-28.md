# R35：双频跳高差异归因（离线审计）

基线 `eda13b6`。本片只新增分析工具和本说明，不改Player、ClassicMovementRules、正式Current、旧测量工具、地图或既有54份收据。

## 结论与可复现证据

现有60/120Hz的21–33mm普通跳高差异，主要来自当前垂直离散积分顺序。`PlayerController.gd`先在非地面帧减重力，地面起跳帧直接赋予完整冲量，再调用`move_and_slide()`：起跳首帧移动`v0×dt`，其后每帧先减重力再移动。第k帧末相对高度可写为：

`h(k) = k*v0*dt - g*dt²*k*(k-1)/2`，k从1开始。

此式已包含离散帧采样，不能直接以连续抛体最高点替代。相较连续式，约多出`v0*dt/2`，因而60Hz比120Hz更高；峰值取整还引入较小差异。

| 方案 | 普通跳实测60−120 | 同一积分式预测 | 连续抛体峰值 |
| --- | ---: | ---: | ---: |
| Current |21.4014mm|21.4028mm|1.32704m|
| Legacy |28.5747mm|28.5739mm|1.14300m|
| Modern |32.4566mm|32.4556mm|1.44780m|

Current蹲跳差23.1371mm，预测23.1389mm；Legacy/Modern蹲跳与普通跳一致。实际12条跳跃轨迹的上升段，以首帧约0.8705mm的分离偏移校准后，逐帧高度与公式的最大差仅 **0.00177mm**；两频差预测误差均小于0.002mm。该常量偏移在起跳首帧已存在，符合胶囊安全分离产生的偏移，但未修改引擎margin或运行禁用对照，因此只将其记录为分离偏移，不宣布已证明具体引擎分支。

12条轨迹均只有一次真实jumped事件，起跳前grounded、jump_requested均为真，全部delta严格为对应物理周期，三方案两频冲量分别保持5.1/6.815535/7.670632m/s。Current蹲跳5.55m/s。未发现本组数据中漏按、重复起跳或混频证据。合成输入时序仍不能代表设备输入延迟。

下降接地时不能沿用纯抛体公式：`_snap_to_floor()`可在目标高度差≤0.45m时直接拉到地面并清零负竖直速度，之后floor状态在碰撞更新后生效。因此“首个grounded样本”的腾空时间包含贴地规则与离散判定，不能用`2*v0/g`直接认定实现错误。分析拟合只覆盖上升段，未拿下降贴地残差掩盖数值误差。

## 下一步有界提案

优先将“输入/时钟缺陷”与“积分偏差”分开处理：这组证据支持先讨论候选垂直积分，而非改冲量补高度。可在独立作者候选验证平均速度/半步重力位移积分，使自由上升贴近连续轨迹，同时保留Current基线。必须分别记录起跳、峰值、下降snap、落地状态时序及低顶碰撞，跑三图冻结跳点和人工对照后再裁定。数学上消除自由抛体离散误差不代表原版CS实现等价，也不自动决定正式目标高度。当前没有启用新候选或修改正式手感。
