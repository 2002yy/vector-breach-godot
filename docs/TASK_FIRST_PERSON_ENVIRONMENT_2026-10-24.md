# 玩家与观战手臂环境候选接线

2026-10-24。续修 #75 分支 `feat/controlled-game-viewport-20261023`，前次验证头 `2a04aff9166aef873b6cf7295763c29695b0787f`，main 基线 `bfc7ba5dbe4e0739f2781a4a45faf05104f37cfe`。本片不等待 CI，不依赖 #76 未合并代码；完整重排见 [执行次序](DEVELOPMENT_ORDER_2026-10-24.md)。

## 行为

`FirstPersonHands` 提供原生手臂 getter、替换前/发布后通知和专用组。ControlledGame 在候选包有效后登记玩家手臂，也处理观战期间动态创建的 WeaponViewModel；替换外观、切人、重建、销毁或切图时先撤销旧材质，按同一地图代次绑定新根。限定同一视口，普通 Main 不启用环境候选。

原生手臂删除前清理实例材质覆盖，与 #75 全身角色采用同一退役原则，不改共享 Mesh 或源材质；拥有者退出先清全部角色/手臂登记，再撤销运行时输入与 SSAO。缺地图包时保持原材质，缺模型时保留既有程序手套/袖子。武器及装备材质不由本片手臂接线自动转换。

同时修复 #75 代码审查指出的遗漏：独立 SubViewport 开启 `audio_listener_enable_3d`，使其世界中的枪声、脚步、命中和 C4 定位音频进入此监听视口。测试核对监听配置及实际游戏流程，不冒充人工音量/空间听感验收。

## 补查发现的材料遗漏

六套原手臂并非都使用专用效果 ShaderMaterial。FBI 蓝袖 `sleeve_fbi` 的源规则为普通 `csgo_character.vfx`，没有布料/皮肤等 F_ 标志，原专用效果清单因此不转换它；最初只给手臂根登记环境后，蓝袖仍在普通 PBR 路径，实际开关像素差为零。不能以根登记成功或手套材质数量非零宣称袖子已接通。

本片为手臂显式候选增加纯角色 PBR 适配，仅接受有原 `csgo_character.vfx` 元数据、无未知启用 F_、无透明/发光/细节/透明折射/清漆等未映射规则的表面。其色彩、纹理、通道、粗糙/金属、法线、AO、UV、剔除、优先级由共用 PBR 复制函数保留；使用临时候选副本，不改原纹理/VMAT/GLB 或原表面。

视觉复核还发现初版蓝袖变灰：新建适配器跨注入 shader 的复制未保留色调，参数读回为白色。本片在最终候选 shader 上重新从原 PBR 明确复制参数，并新增颜色参数与实际画面检查；不能只靠“画面发生变化”验收。关闭/解绑恢复精确原覆盖与像素，而不是只将 shader 权重置零。此适配仍是 Godot 候选，不声称所有 Source 2 直接光/每视图规则等价。

最终串行 Vulkan 三图均通过，每图六外观、每套全部 4–6 个源表面，18 组开/关/再次关闭对照；每图 28 PNG，共 **84 PNG**。审计按原 GLB 的 primitive 数核对覆盖率：T Elite/Phoenix 没有独立袖子，两臂共四个表面，其余六个；不把固定六个当所有角色的正确数目。PNG 再次关闭与初始关闭像素完全相同，原覆盖身份恢复；FBI 蓝袖色调参数正确。截图检查仅判定手臂实际可见、候选生效/回退与色调保留，候选亮度/光泽仍需同原引擎参考，不能当作完整材质观感或 FPS 通过。

完整原生 **208 / RUN_ALL_OK**（本分支不含 #76 新增懒加载用例）、Python 非 Blender **80**、GdUnit **2/2**、导入与三类资源合同、八个规范脚本格式/lint、两个旧文件无新增 lint 错误通过；18 原模型哈希不变。原有四个脏 `.import` 保留且不提交。原引擎 viewmodel 专用光照/曝光/遮挡和武器材质仍须另验。

保留最初探针类型错误、浮点严格比较错误、FBI 零差/灰袖截图，以及并行 Vulkan 时的分配失败与脚本错误日志。分配失败时出现 512 MiB Vulkan 缓冲申请失败和 headless 图片内存申请失败；后续 GPU 与完整原生按串行运行，不把这类失败混入最终 PASS，也不据此宣称已修复引擎或内存性能。
