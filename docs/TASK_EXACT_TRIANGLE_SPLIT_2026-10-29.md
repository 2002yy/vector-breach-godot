# 原三角集合分块实验

基线0b98bc9，仅新增作者探针；未修改生产碰撞、缓存、地图、Player或资源。实际Inferno碰撞缓存HIT49，选取最大wood_001的1,438,118个三角。原缓存形状挂接后删除并释放引用，再按局部XZ三角重心分到4×4网格（13个非空块），同一StaticBody、原mesh变换、layer/mask=1、默认非one-way、继承原backface_collision。不切开三角、不重算法线或顶点。

每个原三角索引只出现一次；每块逐顶点核对原值及绕序，再重建原索引顺序，整个PackedVector3Array字节与原faces完全一致。原faces SHA256存入结果。这里只对三角集合做精确证明，不把物理求解过程视为等价。

单次headless结果（毫秒）：

|项目|耗时|
|---|---:|
|原缓存大shape单次挂接|1682.696|
|作者运行时分桶|487.086|
|所有块shape创建合计|29.870|
|所有块挂接合计|1478.033|
|最大单块创建|10.592|
|最大单块挂接|569.549|

分桶+创建+挂接合计1994.989ms，超过原缓存挂接耗时；不能据此宣称总体加载更快。最大挂接区间降到约570ms，但仍是明显阻塞，分桶本身也是约487ms同步工作。候选每块间等待物理帧，等待时间不计入以上CPU区间。原缓存baseline不承担分桶成本；若未来预烘焙分块缓存，需要另验产物大小、身份和实际总加载。

64组查询中，32组分布采样，32组取1024个候选中重心最靠近内部网格平面的三角。每组原shape/分块均执行双面射线和胶囊overlap布尔查询，64/64配对相同。未记录碰撞法线/位置误差，未验证实际Player接缝跨越、接触数、地面分类、AI、斜坡、低顶或多帧求解稳定性。重心靠近格线不代表完整覆盖所有物理接缝。

证据：D:/AgentGamePipeline/evidence/standard-release-20261029/split/result.json（初轮32组）及result-final.json（位级重建+64组）；格式/lint通过，Godot退出0。source/cache身份随结果记录，原采样与缓存未改。

后续仅建议独立评估预烘焙、密度自适应分块，并对原三角身份、接缝/支撑及实际Player路线做A/B；本实验不启用正式分块、不修改冻结地图几何、不放行帧率或比赛验收。
