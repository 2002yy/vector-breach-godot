## 改动与边界

- Main 的显式开始等待角色准备；逐个角色实例化/配置后让出一帧。启动/选图仍零关卡加载，不在卡片选择时后台预载。
- 构建期间新角色使用 PROCESS_MODE_DISABLED，完整队伍生成后恢复原 process_mode，再发布阵容、炸弹职责、计分板和经济。地图就绪和候选配置沿用完整准备信号。
- 训练补员/回合重置和直接同步 API 保留原行为。代次编号拒绝被后续加载替换的旧协程，Main 也在等待后检查地图代次。
- `spawn_configure_ms` 和总计时含让帧等待；`spawn_work_ms` 是逐角色工作之和，`max_actor_work_ms` 是最大单角色工作时间，`yielded_frames` 为实际让帧次数。这些不是 GPU 最长帧或纯 IO 数据。延迟释放仍不计入 detach。
- 不改地图、碰撞、材质、角色资产和买枪策略。单个角色内部、场景资源、碰撞、导航和候选输入包仍有同步阻塞；本片不承诺总时长缩短或 70% FPS 达标。
