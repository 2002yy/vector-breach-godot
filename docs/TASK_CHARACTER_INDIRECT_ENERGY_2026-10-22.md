# 角色探针模式间接能量与 RGB 软法线

本片基线：main `bd480eac0304878e3c78a3d59af82bfd1da1d13a`（#67 已合并）。分支 `feat/character-indirect-energy-20261022`。普通游戏与唯一试玩包尚未启用此受控候选。

## 原规则与本片实现

之前把静态组合 8199、动态 0 的 SH1 路径视为唯一依据，留下 LPV 适用性疑问。本片取得完整动态组合元数据，并导出原 `csgo_character_vulkan_50_ps.vcs` 的 8199/139303、动态 0/2：动态 0 为无探针回退，动态 2 对应 `D_BAKED_LIGHTING_FROM_PROBE`，确实采样六方向 LPV。139303 还包含当前头部的眼球及贴花静态开关。此证据修正前述疑问，并不证明已取得实际引擎逐对象组合选择或 per-view 常量。

原动态探针组合在覆盖小于 0.99 时，先在六轴评估 SH，再按法线平方混合。因此其缺省项为 `C + L·(N*abs(N))`，不能直接用无探针路径的 `C + L·N`。新 `source_indirect_math.gdshaderinc` 实现此阈值/六轴回退、按原 `normal_softness.rgb * skin_mask` 分别混合映射/几何法线，以及原 BRDF 的漫反射剩余能量与镜面项。镜面归一化仍使用未软化法线的辐照度。

仅在显式绑定 `SourceIndirectInputs` 后，受控 hair 像素替换 Godot 的间接辐照度/反射，再合成原 LPV/原反射数组/原 BRDF 候选；材质 AO 分别作用一次，直接光保留。关闭总候选仍精确回到原材质；不绑定新输入时保留 #67 的镜面候选行为。未改原角色纹理、模型、地图/碰撞、玩法规则。

SH1 输入依据固定 VRF 提交 `54279ec226cc3e1c561b10f11f0f5e879b981e6e` 的 `WorldLightingInfo.StoreSunLight/UpdateAmbientLighting` 从三图原太阳/天空实体推导，保存完整原实体和 lighting 文件哈希，标记 **`viewer-derived-source-sun-SH1`**。Source pitch 正向朝下的方向符号另核对 Valve Source SDK `AngleVectors`。这些是查看器候选；**未采集原引擎 per-view 常量，不能标记原引擎绑定等价**。
