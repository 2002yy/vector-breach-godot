# AI 路线速度与交火机动节奏

基线 `1ee029f197efc27de0c574421813411da72c9647`（#92），分支 `feature/bot-motion-pace`。本片改善默认路线行进和定时左右横移的频率，不宣称所有复杂路径摆动、AI 战术或难度已完成。不等待 CI，不提前合并或更新试玩包。

现场核对三图冻结清单，五份 actor 模板均未设置 aiMoveSpeed，使用 4.35 默认值。原默认 dodge_interval 为 0.9 秒，首次计时为零；横移按固定向量左右交替。实际平地物理对照（120 物理帧）记录两秒位移约 **8.214 → 10.038 m**，稳定水平速度 **4.35 → 5.4 m/s**；固定种子、静止存活靶的八秒交火，横移 **6 → 4 次**、左右反向 **5 → 3 次**、移动帧 **108 → 72 / 480**，射击 **37 → 38 次**。这是一组控制实验，不能推出真实比赛命中率或平衡。

默认基速改为 5.4，上限仍受既有配置 clamp 6.2 限制，显式慢速配置继续生效。精确路径保持原 0.72 倍并限 4.0（默认 3.888），蹲行保持 0.54 倍并限 2.2；交火横移保持原 0.58 倍并限 2.6，避免基速提高放大左右跳动。默认 dodge_interval 改为 1.8，重置后初次横移等待 0.5–1 倍间隔，各机器人使用原有独立随机流；后续仍使用原随机间隔、0.22 秒横移与停步射击规则。没有增添视野、反应或穿墙能力。

数据核对发现 SourceNav 的 precise 同时用于节点到达精度：Dust II **7290/7290**、Mirage **6654/6654**、Inferno **8392/8392** 条链接都标记 precise。早期候选曾将精确路径限到 3.2，几乎抹掉真实三图提速，因此调整为 4.0 上限后重新验证。到达半径、A*、恢复/避障、碰撞形状、楼梯/梯子/水和所有原地图 JSON/哈希都保留。初次完整回归已在取消前完成通过，保留为 `native-before-precise-policy.log`；最终按修正后运行时代码重新完整验证，不混用旧候选结果。

新增原生夹具使用真实 TacticalActor/物理：开阔路线净前进、6.2 上限、显式 2.0 慢速、精确路径速度、蹲姿语义、固定交火反向次数、横移限速及继续开枪。聚焦旧长边、到达半径、坡道、台阶、精确/蹲行、受阻恢复、墙边横移均已检查。两项旧交火夹具原来只给静止靶 100 血，变更机动节奏后靶先死亡而无法观察完整横移窗口；保持原横移断言，只让观察靶在测试窗口存活，并仅重跑这两个失败项后再做完整验证。未为仅修改断言重复整套测试。
