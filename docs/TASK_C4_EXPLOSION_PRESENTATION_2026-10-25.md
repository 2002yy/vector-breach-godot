# C4 世界爆炸与末局结算顺序

基线 `b8c4f1ee168129d0e15db702de5144880e6af1ef`（#90），分支 `feature/c4-explosion-presentation`。增量代码包含 C4 控制器/新世界效果、RoundManager 引爆顺序、Main 伤害与结果展示接线、雷达消耗态过滤和相关测试。不等待新 CI，不提前合并或更新试玩包。

原逻辑在 round_ended 和 complete_round 后才发出 bomb_exploded，且 Main 只处理本地玩家伤害。本片在 end_round 确认当前已安装且 T 以 BOMB EXPLODED 获胜后，先锁定 ROUND_END，发出引爆事件、完成效果与伤害，再通知阶段及回合结算；伤亡触发的歼灭回调因此不能重新改写胜负。玩家与当前 CombatSandbox 的机器人共用原 C4 距离/遮挡公式、原 22m 半径/5.5m 高伤范围与 0.65 护甲穿透参数，不改变导航、碰撞或经济奖励。机器人原先完全漏受 C4 伤害的缺口在本片补上，平衡仍须新头比赛验证。

只有实际安装态 C4 可生成一次爆炸。拆除、歼灭和超时结束均不发引爆事件。C4 消耗后隐藏模型并停止蜂鸣，雷达仅绘制掉落/安装态。新 C4Explosion 包含六个火光和十二个烟尘软边噪声面片、一个无阴影短时点光源，以及 1.4 秒程序生成的空间冲击/低频尾音。尾音使用既有 Master 音量；未新增用户设置、外部纹理、原版模型改写或全屏闪白。

效果展示最初 1.25 秒时，只对 HUD 隐藏结果面板，不延迟权威伤害、经济或记录；总视觉生命周期 2.4 秒，原五秒回合结算间隔不变。死亡继续原观战流程。暂停保持效果年龄和音频，重开/重新携带/重新放置、离开地图或所有者销毁会释放画面与音频。最后一回合仍走既有结束间隔后进入比赛摘要，末局记录在爆炸伤亡落地后保存。

聚焦回归覆盖原子胜负锁定、爆炸先于结算、取消/非爆炸胜利无误触发、防重、初始展示/消退/暂停/回合清理。Main 夹具从真实菜单启动 Gatehouse，在隔离位置检查近处玩家与机器人死亡、远处机器人不受伤、终局记录包含玩家死亡、结果面板时序、观战和比赛摘要清理。这是有控制条件的终局回归，不冒称 18 场比赛或人工试玩。
